# 🔢 Testes de Algoritmos de Ordenação

> Laboratório desenvolvido em **C** para testar, comparar e analisar diferentes algoritmos de ordenação.

---

## 📌 Sobre o projeto

O projeto apresenta uma implementação prática de algoritmos de ordenação, permitindo observar seu funcionamento e comparar a quantidade de **comparações** e **atribuições** realizadas durante a execução.

## ⚙️ Algoritmos implementados

* 🫧 **Bubble Sort**
* 📥 **Insertion Sort**
* 🎯 **Selection Sort**
* 🔀 **Merge Sort**
* ⚡ **Quick Sort**

## 📊 Análise

Durante os testes, os algoritmos são executados sobre os vetores e seus resultados podem ser comparados através de:

* Comparações
* Atribuições
* Resultado final da ordenação

## 🛠️ Tecnologias

**Linguagem:** C
**Compilador:** GCC
**Versionamento:** Git e GitHub

## 🎯 Objetivo

Praticar conceitos de **algoritmos, vetores, funções, recursividade e análise de desempenho**, colocando em prática os conhecimentos estudados em programação.
