# 📊 Testes de Algoritmos de Ordenação

Projeto em **C** desenvolvido para testar e comparar algoritmos de ordenação.

## 🚀 Algoritmos

* Bubble Sort
* Insertion Sort
* Selection Sort
* Merge Sort
* Quick Sort

## ⚙️ Funcionalidades

* Geração de listas aleatórias, ordenadas ou invertidas
* Escolha do algoritmo
* Medição do tempo de execução
* Contagem de comparações e trocas
* Modo passo a passo

## 📈 Métricas

O programa apresenta:

* Tempo de execução
* Quantidade de comparações
* Quantidade de trocas
* Tamanho do vetor

## 🛠️ Tecnologias

**C** • **GCC** • **VS Code**

## 🎯 Objetivo

Praticar algoritmos de ordenação e analisar o desempenho de cada método com diferentes tipos e tamanhos de vetores.
